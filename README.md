# Public_Python

A linguagem foi projetada com a filosofia de enfatizar a importância do esforço do programador sobre o esforço computacional. Prioriza a legibilidade do código sobre a velocidade ou expressividade.

## Sobre

Este projeto contém exemplos, scripts e materiais relacionados à linguagem Python, com foco em boas práticas de legibilidade e organização. A ideia central é mostrar como um código claro e compreensível pode facilitar o desenvolvimento e a manutenção de sistemas.

## Estrutura do Projeto

```text
.
├── Teoria em código/   # Introdução ao Python em português, um conceito por ficheiro (1 a 11) + exercícios
├── En/                 # Notas de referência em inglês (basicNotions.py = Python 3; basicNotionsLegacy.py = Python 2)
├── samples/            # Pequenos programas de exemplo
└── README.md
```

## Como usar

Requer Python 3.

Clone o repositório:

```bash
git clone https://github.com/ricardodsr/Public_Python.git
cd Public_Python
```

Correr um exemplo:

```bash
python "Teoria em código/1 - Introducao.py"
python samples/calculatorAI.py
```

> Os ficheiros em `En/` são notas de leitura: incluem de propósito linhas que lançam erros
> (ex.: `NameError`) para ilustrar o comportamento da linguagem, por isso não correm até ao fim.
